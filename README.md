# 🍽️ Grubz

Grubz is a smart, modern food-ordering platform designed to simplify access to meals — starting with university cafeterias and expanding to local restaurants, offices, and communities.

## 🚀 Live Preview

[🌐 Visit the Landing Page](https://grubz.vercel.app)  
*(coming soon)*

## 🎯 What is Grubz?

Grubz brings together convenience and community by letting users:

- 📱 Pre-order meals from campus cafeterias & favorite local spots  
- ⏰ Skip the queue with instant ordering and scheduled pickups  
- 🏫 Start at USIU - Africa, scale across campuses and neighborhoods

## ✨ Features

- Beautiful landing page with dark/light theme toggle  
- Waitlist signup integrated with Supabase  
- Mobile-first, responsive design  
- Built using modern tools & smooth animations with Framer Motion

## 📦 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Framer Motion  
- **Backend:** Supabase (Database + API)  
- **Deployment:** [Planned: Vercel / Netlify]  
- **Version Control:** Git + GitHub
